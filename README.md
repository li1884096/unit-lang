# 元语言

这是一款中文编程语言，由Rust编写解释器，面向 Windows 和 VS Code。

## 环境

- 安装 Rust stable（包含 `cargo`）并将其加入 PATH。
- 安装 VS Code 。
- unit-lang.exe 是元语言解释器，不要直接运行，放到电脑任意位置 。
- unit-lang-rust.vsix 是VS Code扩展文件，支持元语言的语法高亮和规范格式。
- VS Code 设置 `unitRust.executable` 中填写已构建的 `unit-lang.exe` 本地路径。


## 语言能力

- 缩进代码块、变量赋值、表达式、列表和字典。
- 函数、条件分支、循环、返回、跳过和终止。
- 异常抛出、捕获和始终。
- 数字、文本、布尔、空值、常用内建函数及基础类型方法。
- 类、实例、字段、方法、单继承、类文件导入、别名和类包通配导入。
- `遍历 项目 于 集合:` 遍历列表元素、字符串字符或字典键。
- `读取文件`、`写入文件`、`文件存在` 等标准函数，以及 `标准库/JSON.it` 的 JSON 解析和生成封装；文件读写限制在项目根目录内。
- 静态诊断支持解析可定位的导入类字段、方法及参数数量；运行错误显示函数调用栈。
- VS Code 语法高亮、导入类跳转定义、补全、悬停说明、运行和编辑时诊断。
- 本地直接依赖的添加、安装和清单管理。

具体用法参考基础语法综合示例.it

## 标准库

## 文件与路径类库

`标准库/文件.it` 是常用文件与路径操作的可导入封装，包含读取、写入、追加、按行读写、文件大小与修改时间、创建目录、删除、复制、移动、列出目录、递归列出目录、拆分路径信息和检查文件类型的方法：

例如：

导入 标准库.文件 为 常规
文件工具 = 常规()
文件工具.创建目录("数据")
配置文件 = 文件工具.拼接路径(["数据", "设置.json"])
文件工具.写入(配置文件, "{}")
打印 文件工具.文件名(配置文件)


所有文件系统操作都限制在项目目录中。删除目录只会删除空目录。递归列表不跟随符号链接，最多返回 10000 项、遍历深度最多 64 层；修改时间返回 Unix 时间戳秒数。


## 日期时间类库

`标准库/时间.it` 使用 UTC 时间，时间戳单位是秒。`时间.当前时间()` 默认返回完整的 `年-月-日 时:分:秒`，也可以传入中文占位符格式，如 `时间.当前时间("时:分:秒")` 或 `时间.当前时间("年:月:日 时:分:秒")`。占位符 `年` 输出四位年份，`月`、`日`、`时`、`分`、`秒` 输出两位数，`星期` 输出 ISO 星期序号（一为周一、七为周日）；其他字符作为分隔符原样保留。类库还支持解析日期时间、计算时间差、统一使用 `时间.增加(时间戳, "日", 数量)` 和 `时间.减少(时间戳, "日", 数量)` 调整时间（单位支持年、月、日、时、分、秒）、提取日期部件、查询月份天数、判断闰年、比较时间戳和计算当天/本周起点。遇到目标日期不存在时会调整到当月最后一天（例如 1 月 31 日加一个月得到 2 月末，闰年 2 月 29 日加一年得到平年 2 月 28 日）。

## 字符串类库

`标准库/字符串.it` 封装字符串长度、查找、截取、替换、分割、去除空白、大小写转换、前后缀判断和类型转换。JSON 转换集中在独立的 `标准库/JSON.it`：`JSON.解析(文本)` 把 JSON 文本解析为 Unit 值，`JSON.生成(值)` 把 Unit 值序列化为 JSON 文本。应用程序通过 JSON 类库操作，不直接调用解释器内置 JSON 函数。

## 集合类库

`标准库/集合.it` 封装列表和字典操作，提供追加、删除、反转、去重、数字排序、查找成员以及字典键值访问。数字排序使用插入排序，适合小型列表。

## 数学类库

`标准库/数学.it` 封装常用数学运算，并提供平方根、三角函数、反三角函数、对数、角度与弧度转换、范围限制和常量。三角函数使用弧度。

## SQLite 数据库类库

`标准库/数据库.it` 提供 SQLite 连接、执行和查询。数据库文件路径限制在项目目录内；传入 `":memory:"` 可使用内存数据库。执行和查询使用 SQLite `?1`、`?2` 参数占位符，并把查询结果作为字典列表返回。参数支持空值、布尔值、数字、文本和由 0 到 255 整数组成的字节列表。

例如：

导入 标准库.数据库 为 数据库类库
数据库 = 数据库类库()
连接 = 数据库.打开(":memory:")
数据库.执行(连接, "CREATE TABLE 人物 (姓名 TEXT)", [])
数据库.执行(连接, "INSERT INTO 人物 VALUES (?1)", ["小林"])
打印(数据库.查询(连接, "SELECT 姓名 FROM 人物", []))
数据库.关闭(连接)


## HTTP 网络类库

`标准库/网络.it` 提供同步 HTTP/HTTPS 请求，包含 GET、POST、PUT、DELETE 和自定义请求方法。响应字典包含 `状态码`、`成功`、`响应头`、`响应体`。请求超时 30 秒，响应体限制 10 MB，响应体按 UTF-8 文本处理；POST/PUT 便捷方法默认设置 JSON 内容类型。

例如：

导入 标准库.网络 为 网络工具
网络 = 网络工具()
结果 = 网络.GET("https://httpbin.org/get")
打印(结果.状态码)
打印(结果.响应体)


同一网络类库还提供 TCP/UDP Socket：TCP 支持客户端连接、服务端监听与接受连接、文本收发；UDP 支持绑定地址、发送和接收数据报。`接收TCP` 返回一次读取到的 UTF-8 文本片段，TCP 本身不保留消息边界，应用需自行约定分隔符或长度字段。接收缓冲区最大 1 MiB，超时参数以秒计且范围为 0.01 到 300 秒。

## 系统类库

`标准库/系统.it` 提供当前项目目录、操作系统、系统架构、路径分隔符、Unit 版本、解释器路径和环境变量的只读查询。不存在或无法读取的环境变量返回空值。
